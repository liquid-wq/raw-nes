# Older versions (no longer maintained)

This folder keeps the earlier versions of RAW-NES for reference:

| Folder | Version |
|---|---|
| [`qt/`](qt/) | Qt version 2.x |
| [`python/`](python/) | Python version 1.x |
| [`cores/`](cores/) | FPGA cores used by these versions |

They detect games less reliably and lack the protection against false
unlocks that 3.0.0 has. Please use the current version from the
[Releases](https://github.com/liquid-wq/raw-nes/releases).

These versions are covered by the license in this folder ([`LICENSE`](LICENSE),
[`THIRD-PARTY-NOTICES.txt`](THIRD-PARTY-NOTICES.txt)). The current version uses
the license in the repository root.
